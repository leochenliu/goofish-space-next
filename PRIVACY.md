# 隐私政策 / Privacy Policy

**扩展名称**：Goofish 空格翻页
**最后更新**：2026-10-16

## 中文

本扩展（下称"本插件"）尊重并保护用户隐私。

1. **不收集任何数据**。本插件不收集、不存储、不传输任何个人信息、浏览记录、页面内容或按键记录。
2. **本地运行**。全部功能逻辑均打包在本插件内，在你的浏览器本地执行，不依赖任何远程服务器，也不下载或执行远程代码。
3. **权限用途**。本插件仅在 `goofish.com` 站点注入一段脚本，用于在搜索结果页把你按下的空格键映射为点击页面上的"下一页"按钮。该脚本不读取、不外发页面数据。
4. **无第三方共享**。本插件不与任何第三方共享数据，因为根本不收集数据。
5. **变更**。若本政策有更新，将在本文件所在仓库中更新并注明日期。

如有疑问，请通过本仓库的 Issue 联系。

## English

This extension ("the Extension") respects and protects your privacy.

1. **No data collection.** The Extension does not collect, store, or transmit any personal information, browsing history, page content, or keystrokes.
2. **Local-only operation.** All logic is bundled inside the Extension and runs locally in your browser. It does not rely on any remote server and does not download or execute remote code.
3. **Permission usage.** The Extension injects a single script on `goofish.com` solely to map your Space key to a click on the page's "next page" button on search result pages. The script does not read or transmit any page data.
4. **No third-party sharing.** No data is shared with third parties, because no data is collected.
5. **Changes.** Any updates to this policy will be reflected in this file with an updated date.

For questions, please open an issue in this repository.
